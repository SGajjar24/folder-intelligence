# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `folder-intelligence` seriously. Integrating this tool into enterprise workflows requires trust.

If you discover a security vulnerability (e.g., potential for data loss, PII leakage, or unsafe file operations), please do **NOT** open a public issue.

### Immediate Action
Please email the maintainer directly: **swetang.gajjar@gmail.com**

### Information to Include
1.  **Type of Issue:** (e.g., PII Leak, Unintended Deletion, Path Traversal)
2.  **Reproduction Steps:** How can we reproduce the issue safely?
3.  **Impact:** What is the potential damage?

### Response Timeline
We are committed to addressing security issues promptly. You can expect:
-   **Acknowledgment:** Within 48 hours.
-   **Assessment:** Within 5 days.
-   **Patch/Mitigation:** As soon as verified.

Thank you for helping keep Folder Intelligence safe for everyone.
