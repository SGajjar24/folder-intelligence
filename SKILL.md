# Universal Folder Optimization Expert

## 🎯 Purpose
To transform chaotic, unstructured file systems into pristine, intelligent, and self-documenting repositories. This skill leverages content-aware analysis, hash-based deduplication, and strict naming conventions to ensure consistency and retrievability.

## 🛠 Capabilities

### 1. Structural Intelligence
- **Recursive Audit:** Analyzes directory depth, file distribution, and "clutter metrics" (loose files vs. folders).
- **Auto-Categorization:** Identifies logical groupings (e.g., specific file types, date ranges, project entities) and restructures flat folders into hierarchical trees.
- **Empty Folder Pruning:** Automatically removes empty directories to maintain a lean structure.

### 2. Deep Content Analysis
- **Text Extraction:** Reads PDF, DOCX, and Image (OCR) content to extract metadata.
- **Entity Recognition:** Identifies key entities (e.g., "Acme Bank", "State University", "Client X") from content.
- **Date Inference:** Extracts precise dates (`YYYY-MM-DD`) from document text, falling back to file metadata only when necessary.

### 3. Systematic Renaming
- **Standard Format:** Enforces the `YYYY-MM-DD_Category_Entity_Description.ext` convention.
- **Conflict Resolution:** Handles duplicate names with intelligent suffixing (`_1`, `_2`).
- **Audit Trail:** Logs all renaming actions for reversibility and verification.

### 4. Forensic Deduplication
- **Hash-Based Detection:** Uses SHA-256 hashing to identify exact duplicates, regardless of filename.
- **Smart Pruning:** Retains the copy in the most "logical" location (e.g., deeper in a categorized subfolder) and archives/deletes the redundant copy.

### 5. Self-Documentation
- **README Generation:** Automatically creates `README.md` files in every analyzed folder.
- **Metadata Indexing:** Lists files with their type, size, and efficient summaries in the README.
- **Navigation:** Generates cross-links to subfolders, creating a browsable "wiki-like" experience.

## 🚀 Usage Instructions

### Step 1: Initialize
- Set the `TARGET_DIR` to the root of the chaotic file system.
- Run `universal_intelligence.py` to generate the initial "State of the System" report.

### Step 2: Audit & Plan
- Review the `clutter_report.json` generated by the audit.
- Define custom `KEYWORDS` and `ENTITIES` in `config.py` relevant to the specific domain.

### Step 3: Execute Optimization
1.  **Declutter:** Run `universal_declutter.py` to move loose files into `Category/` subfolders.
2.  **Rename:** Run `universal_namer.py` (Dry Run first) to apply the naming convention.
3.  **Deduplicate:** Run `universal_dedupe.py` to remove exact copies.

### Step 4: Finalize
- Run `universal_intelligence.py` again to generate fresh READMEs and the final `Tree_Structure.md`.
- Verify the system against the `SOP.md` guidelines.

## ⚠️ Critical Rules
1.  **Never Delete Without Hash:** Always verify SHA-256 before deletion.
2.  **Preserve Data:** If a file's content is unique, it must be preserved, even if its name is generic.
3.  **User Confirmation:** For bulk operations (>50 files), always request user approval or use a "Dry Run" mode.
